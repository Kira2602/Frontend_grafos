# Sistema de grafos Graphroom 🖥️🟣➜🟢

Proyecto con **Frontend (Vue 3 + Vite)** y **Backend (JS)**.

---

## 🚀 Instalación :gear:
	
1. Clonar repositorio e instalar el entorno
```bash
git clone [LINK_REPOSITORIO]
```
```bash
cd Frontend_grafos
```
```bash
cd frontend
```
```bash
npm install
```
2. Ejecutar 
```bash
npm run dev
```
## Dependencias necesarias:

cd frontend
